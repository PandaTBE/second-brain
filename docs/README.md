The [project README](../README.md) introduces Second Brain. Read the [security policy](../SECURITY.md) before connecting private sources or a model provider. See the [changelog](../CHANGELOG.md) for release history.

[README проекта](../README.md) знакомит с Second Brain. Перед подключением личных источников и провайдера модели прочитайте [описание безопасности](../SECURITY.md). Изменения выпусков перечислены в [changelog](../CHANGELOG.md).

The guides describe application defaults, not the configuration of a particular user's installation. Screens and source formats may change in later versions. API permissions and provider policies are controlled by the corresponding services.

Руководства описывают настройки приложения по умолчанию, а не конкретную пользовательскую установку. В следующих версиях экраны и форматы источников могут измениться. Права API и правила провайдеров определяются соответствующими сервисами.
