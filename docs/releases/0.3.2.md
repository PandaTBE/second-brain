# Second Brain 0.3.2

2026-11-10 · macOS 14+ · Apple Silicon · MIT

## English

Download from this release's **Assets**:

- `Second-Brain-0.3.2-macos-arm64.zip` — native app and frozen Python service.
- `second-brain-0.3.2-source.zip` — source code, not the compiled application.
- `SHA256SUMS` — checksums for both ZIP files.

The app is ad-hoc signed, **not Developer ID signed or notarized by Apple**.
Fully quit the old app before replacing it and reconnect running MCP clients.
Personal memory stays outside the application. SQLite schema and backup format
v1 are unchanged; take a consistent backup before upgrading.

### Added

GigaCode CLI can now create cards automatically after explicit opt-in. In
**Model and API**, enable its separate automatic-card checkbox and save. Also
enable card processing plus scheduled reconciliation or import-triggered work
in **Memory → Edit**, with synchronization unpaused. Both gates are required;
the CLI permission is off by default. Saving or checking a connection does not
start generation. Manual jobs and text import remain available without opt-in.

The UI resets the checkbox when provider, executable path or model changes.
Older clients omitting `gigacode_auto_cards` mean false. Every backup restore,
including on the same Mac, clears this permission for a fresh local choice.
Source permissions, one effective concurrent CLI request, automatic-attempt
budgets and provider backoff remain in effect. Disabling the permission prevents
new automatic admissions; an already started call may finish.

### Limits and verification

CLI/runtime installation and login remain separate. The help-based connection
check does not verify authentication or generation. Automatic requests may incur
repeated charges; unknown price/usage is not zero cost. Built-in CLI tools may
remain available despite `--safe-mode`; this adapter is not an OS sandbox.

Checks use synthetic executables and disposable state. No real GigaCode model
or corporate authentication requests were made for this change. The 0.3.1 fix
only accepted known zero-valued decision statistics; this release does not fix
or establish compatibility of real CLI prompt/stdin/card-generation behavior.

See [setup](../user-guide.en.md#gigacode-cli-experimental-manual-cards),
[security](../security.en.md#experimental-gigacode-cli-boundary-since-030) and
the [changelog](../../CHANGELOG.md).

## Русский

В **Assets** скачайте `Second-Brain-0.3.2-macos-arm64.zip` и `SHA256SUMS`.
`second-brain-0.3.2-source.zip` содержит исходники, а не готовое приложение.
Нужен Mac с Apple Silicon и macOS 14+. Подпись ad-hoc: **нет Developer ID и
Apple Notarization**. Полностью закройте старое приложение перед заменой и
переподключите MCP-клиенты. Личная память хранится вне приложения. Схема SQLite
и формат копий v1 не менялись; перед обновлением сделайте согласованную копию.

Добавлено отдельное разрешение автокарточек GigaCode CLI, по умолчанию выключенное.
Включите флажок в **Модель и API** и сохраните. В **Память → Изменить** также
включите обработку карточек и расписание либо автоматизацию после импорта;
синхронизация должна быть без паузы. Нужны оба разрешения. Сохранение/проверка
подключения генерацию не запускают; импорт и ручные задачи доступны без флажка.

Смена провайдера, пути CLI или модели сбрасывает флажок интерфейса. Отсутствующее
у старых клиентов поле `gigacode_auto_cards` означает false. Любое восстановление
копии, включая тот же Mac, очищает разрешение. Политики источников, один
одновременный запрос, бюджеты попыток и паузы провайдера сохранены. Выключение
запрещает новые автоматические вызовы; уже начатый может завершиться.

CLI/runtime и вход устанавливаются отдельно. Проверка справки не подтверждает
авторизацию или генерацию. Автозапросы могут повторно расходовать средства;
неизвестная цена не означает бесплатность. Встроенные инструменты CLI могут
работать при `--safe-mode`; адаптер не является sandbox ОС.

Проверки используют синтетические CLI и временные данные, без запросов реальной
модели или корпоративной авторизации. Исправление 0.3.1 касалось только нулевой
статистики решений. Совместимость реальной генерации карточек/передачи stdin
этим выпуском не исправляется и не подтверждается.
