# Second Brain 0.3.1

**2026-11-10 · macOS · MIT** · [User guide](../user-guide.en.md) · [Русский](#русский)

## Download and install

- `Second-Brain-0.3.1-macos-arm64.zip` — app and frozen Python service for
  **Apple Silicon and macOS 14+**.
- `second-brain-0.3.1-source.zip` — source code, not the compiled application.
- `SHA256SUMS` — SHA-256 checksums for the attached ZIP files.

Quit Second Brain completely, extract the app ZIP and replace **Second Brain.app**.
Reconnect running MCP clients after replacement. Personal data is kept outside
the application; the backup format remains v1. The package is **ad-hoc signed,
without Developer ID or Apple notarization**. If you trust it, use Apple's
[Open Anyway flow](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
when macOS blocks it; do not disable Gatekeeper.

## Fixed

GigaCode CLI can report `stats.tools.totalDecisions` as a dictionary of decision
counters. The response parser previously expected a number for every `total…`
field and rejected this dictionary even when all decisions were zero.

The patch accepts known decision names with integer zero values. Nonzero tool
activity, unknown names and malformed values remain rejected. Prompt/stdin
transport, source permissions, manual-only generation and process limits are
unchanged. Accepting the response envelope does not itself establish that a
session returned valid card JSON; existing card validation still applies.

The regression is covered by **77 parser tests with 100% module coverage**, plus
a synthetic frozen-helper-to-CLI card flow containing the zero-valued dictionary.
No new real GigaCode model requests were made for this fix. Real corporate
authentication and card generation through that backend remain unverified here.

GigaCode CLI remains a separate, already authenticated installation. Built-in
tools may remain available; `--safe-mode` and process limits are not a sandbox.
See [setup](../user-guide.en.md#gigacode-cli-experimental-manual-cards),
[security](../../SECURITY.md) and the [changelog](../../CHANGELOG.md).

## Русский

Скачайте `Second-Brain-0.3.1-macos-arm64.zip` и `SHA256SUMS` в **Assets**.
Пакет предназначен для **Apple Silicon и macOS 14+**. Полностью завершите
Second Brain, распакуйте ZIP и замените **Second Brain.app**. После замены
переподключите MCP-клиенты. Данные хранятся вне приложения; формат копий v1 сохранён.
Подпись — **ad-hoc, без Developer ID и нотарификации Apple**. При доверии выпуску
используйте системное **Всё равно открыть**, не отключая Gatekeeper.

Исправлена ложная ошибка неподдерживаемого ответа GigaCode CLI: поле
`stats.tools.totalDecisions` может быть словарём счётчиков, а проверка ожидала число.
Теперь известный словарь с нулевыми целочисленными значениями принимается.
Ненулевая активность, неизвестные поля и некорректные значения по-прежнему
отклоняются. Промпт/stdin, разрешения источников, ручная генерация и лимиты процесса
не менялись. Успешный разбор оболочки ещё не подтверждает корректность JSON карточки;
прежний валидатор карточек продолжает работать.

Прошли **77 тестов парсера, покрытие модуля 100%**, и синтетическая цепочка
frozen helper → CLI → карточка с таким словарём. Новых запросов к реальной модели
для исправления не выполнялось; корпоративный вход и генерация через этот backend
здесь не проверены. CLI устанавливается и авторизуется отдельно. Встроенные
инструменты могут оставаться доступны; `--safe-mode` и лимиты не являются sandbox.

Подробнее: [настройка](../user-guide.ru.md#gigacode-cli-экспериментальные-ручные-карточки),
[безопасность](../../SECURITY.md), [changelog](../../CHANGELOG.md).
