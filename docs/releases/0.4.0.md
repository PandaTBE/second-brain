# Second Brain 0.4.0

2026-11-16 · macOS 14+ · Apple Silicon · MIT

## English

Download from this release's **Assets**:

- `Second-Brain-0.4.0-macos-arm64.zip` — native app and frozen Python service.
- `second-brain-0.4.0-source.zip` — source code, not the compiled application.
- `SHA256SUMS` — checksums for both ZIP files.

The app is ad-hoc signed, **not Developer ID signed or notarized by Apple**.
Fully quit the old app before replacing it and reconnect running MCP clients.
Personal memory remains outside the application; take a consistent backup first.

### Tasks and progression

- Open **Задачи** in the native app (Command–Shift–T) or the local web interface.
  Both share a kanban board with To Do, Doing and Done columns, drag and drop,
  status buttons and confirmed deletion.
- Create ordinary or daily tasks and choose one of five stats and a difficulty.
  Completion awards 10, 25 or 50 XP. The profile shows stats, level, rank and
  progress to the next level. Repeated completion never duplicates rewards;
  undoing completion removes its reward. Deleting a task keeps earned XP.
- Dailies start fresh on each local calendar day while earlier XP stays saved.
  Missed days cause no penalty. No account, model call or external task service
  is required.
- Tasks and progress are saved in the existing local SQLite database and backups.
  They are excluded from memory search, generated cards and MCP.

The board follows [Trello](https://trello.com/guide/trello-101) and the task/XP
pattern follows [Habitica](https://habitica.com/static/features), using the
application's own interface and assets. Existing 0.3.3 fixes remain included.

### Upgrade and backup compatibility

The database gains tracker tables; existing memory and card data are preserved.
Backup format v1 stays unchanged. The exact pre-tracker 0.3.x schema is accepted
and migrated only in the inspected staging copy; unknown schemas remain rejected.
Restoring replaces tasks and XP with the backup's state. A pre-tracker backup
restores an **empty board and zero XP**. Older applications cannot restore 0.4.0
backups. Downgrading an upgraded database to 0.3.x is unsupported; the older app
cannot create its own backups from the tracker schema. Keep a pre-upgrade backup.

### Verification limits

Local validation passed 1,835 Python tests (one skipped; 90.64% coverage),
37 JavaScript tests, 55 Swift core checks and the native restore-state checks.
Claude reviewed the implementation in ponytail mode; Codex implemented it through
ORCA. The portable bundle passed privacy scanning, isolated HTTP/FTS5/MCP and
synthetic local-model smoke checks. Web interactions and native creation,
completion and persistence after restarting the extracted ZIP were checked with
disposable data. Tests use synthetic tasks and disposable databases. Full VoiceOver behavior and
transfer to a second physical Mac are not established by automated checks.
The package is for Apple Silicon; there is no Intel or universal build.
Local SQLite and managed backup copies remain unencrypted; age export is separate.

and [security policy](../../SECURITY.md).

### Задачи и прокачка

- Новый раздел **Задачи** в приложении (Command–Shift–T) и локальном вебе:
  общая доска «К выполнению / В работе / Готово», перетаскивание, кнопки смены
  статуса и удаление с подтверждением.
- Обычные и ежедневные задачи, пять характеристик, награда 10/25/50 XP по
  сложности, уровни, ранги и полоса прогресса. Повторное завершение не удваивает
  награду; отмена выполнения снимает её, удаление сохраняет заработанный XP.
- Daily снова доступны каждый местный календарный день, прежние награды
  сохраняются. За пропуски нет штрафов. Учётная запись и модель не нужны.
- Задачи и прогресс входят в локальную SQLite и резервные копии, не попадают
  в поиск памяти, карточки модели или MCP. Исправления 0.3.3 сохранены.

Добавлены таблицы трекера с сохранением прежней памяти и карточек. Формат копий
v1 прежний: точная схема 0.3.x до трекера мигрирует только в проверяемой копии,
неизвестная схема отклоняется. Восстановление заменяет доску и XP состоянием
архива; копия до трекера восстанавливает **пустую доску и нулевой XP**.
Старое приложение не восстанавливает копии 0.4.0. Откат обновлённой базы на 0.3.x
не поддерживается: старое приложение также не создаст копию новой схемы.
Сохраните копию до обновления.

Автоматические проверки используют искусственные задачи и временные базы;
полная проверка VoiceOver и перенос на второй физический Mac ими не подтверждаются.
Сборка только Apple Silicon. SQLite и локальные копии не зашифрованы;
зашифрованный age-экспорт выполняется отдельно.
