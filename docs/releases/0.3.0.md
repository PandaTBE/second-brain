# Second Brain 0.3.0

**2026-11-10 · macOS · MIT** · [User guide](../user-guide.en.md) · [Русский](#русский)

## Download and install

- `Second-Brain-0.3.0-macos-arm64.zip` — the native app and frozen Python service
  for **Apple Silicon and macOS 14+**.
- `second-brain-0.3.0-source.zip` — reviewed source, not the compiled app.
- `SHA256SUMS` — SHA-256 checksums for the attached ZIP files.

Extract the app ZIP, move **Second Brain.app** to **Applications**, and open it.
The app does not require Xcode, Python, uv or a source checkout on the recipient's
Mac. There is no Intel/universal asset. The package is **ad-hoc signed, without
Developer ID or Apple notarization**. If you trust the release, use Apple's
[Open Anyway flow](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
when macOS blocks it; do not disable Gatekeeper. A checksum detects changed bytes
and does not establish publisher identity.

## New in 0.3.0: GigaCode CLI cards

- Select experimental **GigaCode CLI** in Model and API. It uses the login of a
  separately installed headless CLI on the same Mac; no model API token is entered
  in Second Brain. GigaCode and its required runtime are separate installations.
- Set an absolute executable path when the app's `PATH` cannot find `gigacode`.
  `default` uses the model configured in CLI; an explicit model ID is also accepted.
  The connection check validates required `--help` capabilities without pinning a
  CLI version. It does **not** verify login or invoke generation.
- Create cards through explicit manual jobs. Automatic text imports remain
  available, but automatic card generation and automatic retries do not invoke
  this provider. Effective concurrency is one; output and time are bounded.
- The prompt travels through stdin, and the final JSON result goes through the
  existing card and exact-quotation validation. The connection uses **external
  model** source permissions. Usage is counted when reported; missing price or
  usage does not imply free use.

`--safe-mode` disables customizations and MCP, but built-in file, shell or network
tools may remain available. The adapter, private working directory and process
limits are **not a sandbox**. Source text can contain prompt injection; rejecting
reported tool activity after execution cannot prevent or undo it. CLI traffic,
authentication and its own history/configuration follow that client's behavior.
See [security](../../SECURITY.md) before enabling the provider for private material.

## Upgrade and verification

Quit Second Brain and reconnect running MCP clients after replacement. Keep a
consistent backup before upgrading. The release preserves the per-user archive in
`~/Library/Application Support/Second Brain`; checkout-local `.data` is separate
and is not migrated automatically. No personal memory, source connections or keys
are included in the release. The v1 backup format is unchanged. A foreign restore
clears the old CLI path/model selection; configure the receiving Mac explicitly.

Validation includes **1,709 Python tests, 90.44% coverage, 31 JavaScript tests and
53 native CoreChecks**, plus synthetic frozen-helper-to-CLI card generation and
the web settings flow. Real GigaCode corporate authentication/model generation and
the native GUI workflow remain unverified. A physical second-Mac transfer, full
CJK/VoiceOver behavior and real embedding relevance/cold timings remain unverified;
the semantic quality target is not a passed benchmark. Ollama/weights are separate
installations, and exact source quotes are evidence of wording, not proof of truth.

See the [changelog](../../CHANGELOG.md) and [setup guide](../user-guide.en.md).

## Русский

Скачайте в **Assets** `Second-Brain-0.3.0-macos-arm64.zip` и `SHA256SUMS`.
Это приложение с Python-сервисом для **Apple Silicon и macOS 14+**. Распакуйте ZIP,
перенесите **Second Brain.app** в **Программы** и откройте. Xcode, Python, uv и
исходники получателю не нужны; Intel/universal-сборки нет. Подпись — **ad-hoc, без
Developer ID и нотарификации Apple**. При доверии выпуску используйте системное
**Всё равно открыть**, не отключая Gatekeeper. Архив
`second-brain-0.3.0-source.zip` содержит исходники, а не готовое приложение.

В 0.3.0 добавлен экспериментальный провайдер **GigaCode CLI** для карточек:

- Установите CLI и его runtime отдельно на тот же Mac и выполните обычный вход.
  В Second Brain выберите GigaCode CLI; API-токен модели вводить не нужно.
- Укажите полный путь к исполняемому файлу, если приложение не находит `gigacode`
  через свой `PATH`. Модель `default` использует настройки CLI; доступен явный ID.
  Проверка справки ищет нужные возможности без привязки к версии. Вход и генерацию
  она не проверяет.
- Явно запускайте ручные задачи карточек. Автоимпорт текста может продолжаться;
  автогенерация и автоповторы CLI не запускают. Одновременно работает один запрос,
  время и вывод ограничены. Промпт передаётся через stdin; ответ проходит прежние
  проверки карточки и точных цитат.
- Это **внешняя модель** для политик источника. Токены учитываются, если CLI их
  сообщает; неизвестные цена/usage не означают бесплатность.

`--safe-mode` отключает пользовательский контекст, расширения и MCP, но встроенные
файловые, shell- и сетевые инструменты могут оставаться доступны. Адаптер, рабочая
папка и лимиты **не являются sandbox**. Инструкция в тексте источника всё ещё может
вызвать действие; отклонение отчёта о tool activity после выполнения не отменяет
последствий. Сеть, авторизация и собственная история определяются самим CLI.
Подробнее — [безопасность](../../SECURITY.md).

Перед обновлением сделайте согласованную копию, завершите приложение и после
замены переподключите MCP-клиенты. Пользовательский архив остаётся в
`~/Library/Application Support/Second Brain`; проектная `.data` отдельно и
автоматически не переносится. Личная память, источники и ключи в выпуск не входят.
Формат копии v1 сохранён; при чужом восстановлении старые путь CLI и модель
очищаются, принимающий Mac настраивается заново.

Проверены **1709 Python-тестов, покрытие 90,44%, 31 JS-тест и 53 CoreChecks**,
синтетическая цепочка frozen helper → CLI → карточка и веб-настройки. Реальный
корпоративный вход/генерация GigaCode и нативный GUI ещё не проверены. Физический
второй Mac, полный CJK/VoiceOver и качество/холодное время настоящих embeddings
не подтверждены. Ollama/веса устанавливаются отдельно; цитата подтверждает
формулировку источника, а не её истинность.
