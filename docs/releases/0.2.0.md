# Second Brain 0.2.0

**2026-11-06 · macOS · MIT** · [User guide](../user-guide.en.md) · [Русский](#русский)

## Download and install

- `Second-Brain-0.2.0-macos-arm64.zip` — the native app and frozen Python service
  for **Apple Silicon and macOS 14+**.
- `SHA256SUMS` — checksums for the attached release files.
- GitHub's automatic **Source code** archives contain source, not the compiled app.

Extract the ZIP, move **Second Brain.app** to **Applications**, and open it.
Xcode, Python, uv and the source checkout are not required. There is no Intel or
universal build in this asset. The package is **ad-hoc signed, without Developer ID
or Apple notarization**. If you trust the release, use Apple's documented
[Open Anyway flow](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
when macOS blocks it; do not disable Gatekeeper. A matching checksum detects a
changed file and does not establish publisher identity.

## New in 0.2.0

- **Source permissions:** independent import, app search, MCP, local-model and
  external-model controls, plus local-path and selected Notes-folder exclusions
  with a preview. Existing source/mailbox gates are preserved.
- **Local semantic/hybrid search:** opt-in indexing through a separately installed
  Ollama embedding model, with BM25 fallback and visible partial coverage.
  Weights are never downloaded automatically; reading memory makes no paid model call.
- **Evidence and fact history:** exact quotes, revision-aware bounded context,
  explicit copying and conservative facts/decision history. MCP now has seven
  read-only tools; the four original names and required arguments stay compatible.
- **Quick search:** menu-bar panel and configurable Command–Option–Shift–Space,
  keyboard selection and explicit context copy for the selected material.
  No Accessibility or Input Monitoring permission is required.
- **Backup and transfer:** consistent local snapshots, optional managed retention,
  standard-age password export, inspection and coordinated restore/rollback.
  Foreign-installation restores require fresh credentials and explicit local/Notes
  source selection; automatic work stays paused until reviewed.
- **Apple Notes and Outlook:** selected Notes folders through macOS Automation;
  Outlook.com/Microsoft 365 Inbox through Graph device-code sign-in with your
  registered Client ID. Protected Notes and attachments are skipped.
- **Corporate model APIs:** a disabled-by-default internal-network option for a
  custom HTTPS API, retaining TLS verification and destination restrictions.

See the [changelog](../../CHANGELOG.md) for details and the
[Outlook registration guide](../outlook-setup.md#english) for setup.

## Upgrade and data handling

Back up your existing SQLite/configuration consistently before upgrading from
0.1.0, then quit the app and reconnect running MCP clients after replacement.
The app preserves its per-user archive in
`~/Library/Application Support/Second Brain`; a checkout's `.data` is separate
and is not moved automatically. No personal memory, source connections or keys
are included in the release.

Compatible application migrations preserve legacy source/mailbox behavior and
existing card settings/budgets. Semantic indexing remains opt-in. Fact history
starts when the feature observes revisions; missing older history is not invented.
Saved ready cards can be projected into facts without a model request.

The v1 backup format accepts the exact supported schema, not arbitrary SQLite
files or a bare manual 0.1.0 snapshot. Plaintext archive and total unpacked content,
including manifest, each cap at **128 MiB**; inspection expires after ten minutes.
Managed local copies and temporary staging are **unencrypted**. Only the separate
age export is password-encrypted. Backups include hidden cached material and
retained history; visibility flags do not redact them. Keychain secrets and model
weights are excluded. Keep the export password separately.

## Verification limits

Native restore/Unicode flows and portable-package boundaries were checked on the
validation Mac. A physical second-Mac transfer, full CJK/VoiceOver behavior and
real embedding relevance/cold timings remain unverified; the semantic quality
target is not a passed benchmark. Ollama and weights are separate installations.

Exact quotation is evidence of source wording, not proof of truth. MCP recipients
may use cloud models; their input tokens are separate from Second Brain's model
calls. Source exclusions do not revoke already received text or securely erase
SQLite/WAL/backups. Review [security](../../SECURITY.md) before connecting sources.

## Русский

В **Assets** скачайте **Second-Brain-0.2.0-macos-arm64.zip** и `SHA256SUMS`.
Это нативное приложение с Python-сервисом для **Apple Silicon и macOS 14+**.
Распакуйте ZIP, перенесите **Second Brain.app** в **Программы** и откройте.
Xcode, Python, uv и исходники получателю не нужны; сборки Intel/universal нет.
Подпись — **ad-hoc, без Developer ID и нотарификации Apple**. При доверии выпуску
используйте системное **Всё равно открыть**, не отключая Gatekeeper.

В 0.2.0 добавлены:

- Раздельные разрешения источника для импорта, приложения, MCP, локальной и
  внешней модели; исключения локальных путей/папок Notes с предпросмотром.
- Явно включаемый локальный семантический/гибридный поиск с отдельной установленной
  embedding-моделью Ollama, возвратом к BM25 и показом неполного покрытия.
- Пакеты точных цитат, явное копирование контекста, факты и наблюдаемая история
  решений; семь инструментов MCP с совместимостью четырёх прежних вызовов.
- Быстрый поиск из меню или Command–Option–Shift–Пробел, настройка сочетания,
  клавиатурный выбор и контекст выбранного материала без Accessibility/отслеживания ввода.
- Согласованные локальные копии, расписание/очистка управляемых копий, парольный
  age-экспорт, проверка и восстановление с откатом. После переноса нужны новые
  секреты и явный выбор локальных/Notes-источников; автоматическая работа на паузе.
- Apple Заметки с выбором папок и разрешением «Автоматизация»; входящие
  Outlook.com/Microsoft 365 через Graph и собственный Client ID. Защищённые заметки
  и вложения не читаются. См. [настройку Outlook](../outlook-setup.md#russian).
- Выключенное по умолчанию разрешение внутренней сети для собственного HTTPS API
  модели с сохранением проверки TLS и ограничений назначения.

Перед обновлением с 0.1.0 сделайте согласованную копию SQLite/настроек, завершите
приложение и после замены переподключите MCP-клиенты. Данные остаются в
`~/Library/Application Support/Second Brain`; проектная `.data` не переносится
автоматически. Прежние настройки источников/почты и бюджеты карточек сохраняются.
Embeddings включаются отдельно; отсутствующая старая история фактов не выдумывается.

Формат копии v1 требует точной поддерживаемой схемы и не принимает произвольную
SQLite/ручной снимок 0.1.0. Открытый архив и сумма распакованных данных с manifest
ограничены **128 МиБ**; проверка действует десять минут. Локальные копии и временная
подготовка **не зашифрованы**, пароль защищает только отдельный age-экспорт. Копия
включает скрытые материалы/историю; политики видимости не вырезают их. Keychain
и веса моделей не экспортируются; пароль архива храните отдельно.

Нативное восстановление/Unicode и границы переносимого пакета проверены на
проверочном Mac. Физический второй Mac, полный CJK/VoiceOver и качество/холодное
время настоящей embedding-модели не подтверждены. Цитата не доказывает истинность,
MCP-клиент может передавать контекст своей облачной модели, исключение источника
не отзывает полученный текст и не гарантирует стирание SQLite/WAL/копий.
