# Second Brain 0.3.3

2026-11-11 · macOS 14+ · Apple Silicon · MIT

## English

Download from this release's **Assets**:

- `Second-Brain-0.3.3-macos-arm64.zip` — native app and frozen Python service.
- `second-brain-0.3.3-source.zip` — source code, not the compiled application.
- `SHA256SUMS` — checksums for both ZIP files.

The app is ad-hoc signed, **not Developer ID signed or notarized by Apple**.
Fully quit the old app before replacing it and reconnect running MCP clients.
Personal memory stays outside the application. SQLite schema and backup format
v1 are unchanged; take a consistent backup before upgrading.

### Fixed

GigaCode can save headless card-generation requests as chats in a watched
`projects` directory. Importing those chats could create new card jobs and repeat
the cycle. Second Brain now marks its service prompts and excludes recognized
service sessions as a whole, including assistant output, from Qwen history
import. Both buffered and streaming readers apply the filter. Legacy exact
prompts and reserved workspace metadata under standard macOS/Linux temporary
directories are also recognized. Ordinary conversations discussing these strings
and ordinary project paths remain importable; original JSONL files stay unchanged.

Recognizable already-imported service records are blocked before claiming a
card attempt and at final provider admission. The parser cache is refreshed so a
complete reimport rechecks unchanged logs and removes old service chunks/cards.
An already admitted model request may finish.

### Recover an existing loop

1. Disable GigaCode automatic cards or pause global synchronization.
2. Install this version and fully reimport the affected Qwen history source.
3. Wait for every batch to complete without errors before resuming automation.

Old assistant-only chunks cannot establish service provenance on their own.
They may remain until the original session is reimported. If a log is missing or
its format is unsupported, exclude its service file/directory through source
permissions before resuming. Custom temporary directories require prompt/marker
evidence. The application does not delete the original CLI history.

The CLI remains separately installed and authenticated. Its default-off automatic
permission and general Memory automation are still both required. Source
permissions, serialized CLI calls, budgets and backoff remain in effect. Built-in
CLI tools may remain available despite `--safe-mode`; this adapter is not an OS
sandbox. Unknown usage or price does not mean zero cost.

Verification uses synthetic executables and disposable data, including a fake
headless request saved as a transcript and reimported without a new card job.
No real GigaCode model or corporate-authentication requests were made for this fix.
These checks do not establish compatibility of a particular real CLI installation.

See [recovery details](../user-guide.en.md#when-gigacode-imports-its-own-service-chats),
[security](../security.en.md#experimental-gigacode-cli-boundary-since-030) and
the [changelog](../../CHANGELOG.md).

## Русский

В **Assets** скачайте `Second-Brain-0.3.3-macos-arm64.zip` и `SHA256SUMS`.
`second-brain-0.3.3-source.zip` содержит исходники, а не готовое приложение.
Нужен Mac с Apple Silicon и macOS 14+. Подпись ad-hoc: **нет Developer ID и
Apple Notarization**. Полностью закройте старое приложение перед заменой и
переподключите MCP-клиенты. Личная память хранится вне приложения. Схема SQLite
и формат копий v1 не менялись; перед обновлением сделайте согласованную копию.

Исправлен цикл, возникавший при импорте служебных headless-чатов GigaCode из
отслеживаемой папки `projects`: запрос карточки попадал в память и порождал новую
генерацию. Новые запросы Second Brain помечаются. Распознанная служебная сессия,
включая ответ ассистента, исключается целиком при обычном и потоковом импорте
истории Qwen. Распознаются также старый точный запрос и метаданные служебного
каталога в стандартных временных папках macOS/Linux. Обычные обсуждения этих
строк и обычные проекты продолжают импортироваться. Исходные JSONL не меняются.

Распознаваемые старые материалы блокируются до захвата попытки и при финальном
допуске к модели. Обновление кэша парсера позволяет повторному импорту проверить
неизменённые журналы и убрать старые служебные фрагменты/карточки из памяти.
Уже начатый запрос модели может завершиться.

**Если цикл уже возник:**

1. Выключите автокарточки GigaCode или поставьте общую синхронизацию на паузу.
2. Установите 0.3.3 и полностью повторите импорт затронутого источника истории Qwen.
3. Дождитесь завершения всех пакетов без ошибок и только затем включайте автоматизацию.

Старые фрагменты только с ответом ассистента нельзя надёжно распознать без
исходной сессии; до повторного импорта они могут оставаться в памяти. Если
журнал удалён или его формат не поддерживается, исключите служебный файл/папку
через разрешения источника до возобновления. Для нестандартной временной папки
нужны признаки в запросе или маркер. История самого CLI не удаляется.

CLI и вход устанавливаются отдельно. По-прежнему нужны отдельное разрешение
автокарточек, выключенное по умолчанию, и общая автоматизация Памяти. Политики
источников, один одновременный CLI-запрос, бюджеты и паузы провайдера сохранены.
Встроенные инструменты могут работать при `--safe-mode`; адаптер не является
sandbox ОС. Неизвестная цена не означает бесплатность.

Проверки используют искусственный CLI и временные данные, включая сохранение
служебного запроса в журнал и импорт без новой задачи генерации. Реальные запросы
модели GigaCode и корпоративной авторизации не выполнялись. Эти проверки не
подтверждают совместимость конкретной реальной установки CLI.
