# Second Brain 0.1.0

**2026-11-04 · macOS · MIT** · [User guide](../user-guide.en.md) · [Русский](#русский)

## Download assets

Attach these files to the GitHub release as **Assets**:

- `Second-Brain-0.1.0-macos-arm64.zip` — the native application with its Python
  service, for Apple Silicon Macs running macOS 14 or later.
- `SHA256SUMS` — SHA-256 checksums for the release files.
- The separately prepared source archive, if offered. GitHub's automatically
  generated **Source code** archives contain source, not a ready-to-run app.

Extract the application ZIP, move **Second Brain.app** to **Applications**, and
open it. The recipient does not need Xcode, Python, uv or the source checkout.
This asset does not include an Intel or universal build.

The current package is **ad-hoc signed, without Developer ID or Apple
notarization**. macOS may block an internet download. If you trust this release,
follow [Apple's documented opening flow](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac),
without disabling Gatekeeper. A matching SHA-256 detects a changed archive; it
does not establish trust in its publisher.

## Included

- A native macOS app with Dock and menu-bar operation.
- Shared local SQLite memory, FTS5/BM25 search and evidence-linked cards.
- A faster HTML graph with batched connections, reusable nodes, indexed search
  and frame-coalesced zoom/pan; relationships and keyboard navigation are retained.
- Read-only MCP tools for Codex, Claude and compatible clients.
- Selected sessions, notes, Notion pages, GitHub materials and Gmail/Yandex Inbox
  import; bounded background synchronization and optional model processing.
- Qwen API cloud cards and local Qwen cards through separately installed Ollama.
  The local connection needs no API token, uses downloaded models with no cloud
  fallback, and processes one card request at a time. See the [local setup](../user-guide.en.md).
- Configurable card concurrency, bounded retries, provider pauses and safe card
  error categories. The memory screen explains automatic retries and offers an
  explicit Retry all errors button with a fresh bounded attempt budget. Local
  search and import remain available during model holds.

Add your own sources and credentials on first use. No personal memory, account
connections or tokens are supplied in the package. Data is stored outside the
bundle in `~/Library/Application Support/Second Brain`; a source-build `.data`
archive is separate and is not migrated automatically. Configure MCP after
placing the app in its final location, and reconnect clients after updates.

## Limits

SQLite and backups are not encrypted by the application. Secret redaction is
heuristic; optional cloud processing sends source text to your selected provider.
Local card generation uses separately installed Ollama and model weights; it does
not change the data handling of remote imports or your connected MCP client.
MCP grants read access to this shared memory. Review [SECURITY](../../SECURITY.md)
and the source/import limits in the [guide](../user-guide.en.md). Packaging checks
are not a guarantee that every security issue has been found.

## Русский

Готовое приложение находится в **Assets →
Second-Brain-0.1.0-macos-arm64.zip**. Это сборка для **Apple Silicon и macOS 14+**,
с включённым Python-сервисом. Распакуйте ZIP, перенесите **Second Brain.app** в
**Программы** и откройте. Xcode, Python, uv и исходники устанавливать не нужно.
Сборки для Intel в этом архиве нет. Сверьте архив с `SHA256SUMS` того же выпуска.

Текущая подпись — **ad-hoc, без Developer ID и нотарификации Apple**. При
блокировке macOS и доверии к выпуску используйте системный путь **Системные
настройки → Конфиденциальность и безопасность → Всё равно открыть**. Не отключайте
Gatekeeper. Контрольная сумма обнаруживает изменение файла, но не доказывает
надёжность его автора.

Доступны облачная Qwen API с токеном и локальная Qwen через Ollama без токена
модели. Ollama и веса нужно установить отдельно; в ZIP их нет. Для локального
режима используется один запрос генерации одновременно и нет перехода в облако.
См. [инструкцию подключения](../user-guide.ru.md).

При первом запуске добавьте свои источники и, при необходимости, токен облачной модели.
Личные материалы, подключения и секреты сопровождающего в архив не включаются.
Данные пользователя находятся в `~/Library/Application Support/Second Brain`;
проектная `.data` автоматически не переносится. Настройте MCP после переноса
приложения в постоянную папку и переподключайте клиенты после обновлений.

Память и резервные копии не шифруются приложением, маскирование эвристическое, а
разрешённая облачная обработка карточек передаёт текст выбранному провайдеру.
Локальная Ollama не меняет передачу данных при импорте удалённых источников или
работе подключённого MCP-клиента. Подробнее —
[руководство](../user-guide.ru.md) и [безопасность](../../SECURITY.md).
